# MentorApp

Приложение для поиска ментора.

## Установка базы данных

1. Откройте SQL Server Management Studio (SSMS)
2. ПКМ по папке **Databases** → **Import Data-tier Application**
3. Выберите файл `MentorDB.bacpac`
4. Нажмите **Finish**

## Запуск проекта

Откройте `MentorApp.sln` в Visual Studio и нажмите **F5**.
